### 2) Тема проекта:
**Система приёма и надёжной обработки платёжных транзакций с эмуляцией POS-терминала**

### 3) Задачи:
- Разработка эмулятора POS-терминала на Raspberry Pi (или аналог): кнопки/энкодер для ввода суммы и подтверждения операции, световая/дисплейная индикация статуса транзакции (ожидание/обработка/успех/ошибка).
- Публикация событий транзакций в Apache Kafka от нескольких независимых терминалов для асинхронной надёжной доставки без блокировки устройства-источника.
- Разработка backend сервера на Go: consumer Kafka с идемпотентной обработкой транзакций (дедупликация по уникальному `transaction_id` через Redis), REST API для статуса и истории операций.
- Разработка Android-приложения кассира (Java): просмотр статуса транзакций в реальном времени, история операций.
- Нагрузочное тестирование пайплайна обработки транзакций.

### 4) Ожидаемый результат к декабрю 2026 года:
Работающий прототип, включающий:
- эмулятор POS-терминала на Raspberry Pi (или аналог);
- Kafka-очередь событий транзакций;
- Go-сервер с идемпотентной обработкой транзакций;
- Android-приложение кассира (Java) с историей операций и статусом в реальном времени;
- документированный REST API (Swagger).
